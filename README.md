# TDS-ChatApp

TDS-ChatApp es una aplicación de chat construida con Java y Maven. Permite a los usuarios gestionar contactos, enviar mensajes y mucho más.


## Funcionalidades

- Agregar y eliminar contactos
- Enviar y recibir mensajes
- Gestionar perfiles de usuario
- Generar un PDF con información del usuario (para usuarios premium)

## Instalación
1. Clona el repositorio:
   ```sh
   git clone https://github.com/PepeGdlT/TDS-ChatApp.git
   ```
2. Navega al directorio del proyecto:
   ```sh
   cd TDS-ChatApp
   ```
3. Construye el proyecto usando Maven:
   ```sh
   mvn clean install
   ```
## Dependencias

 - JUnit 3.8.1
 - driverPersistencia 2.0 
 - JCalendar 1.4 
 - H2 Database 1.4.200 
 - EclipseLink 2.7.7 
 - javax.persistence-api 2.2 
 - XChart 3.5.0 
 - iTextPDF 5.5.13.4
